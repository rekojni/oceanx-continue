# Two-minute IS615 walkthrough

Use a facilitator demonstration/test session and your actual researcher account. Keep `/research` open in another tab. Complete the physical activity beforehand and record the submission honestly; the two-minute video can show the artefact without pretending the audit itself took seconds. Prepare a Group B session using automatic allocation; if initially A, finish it and start a separate demonstration session.

| Time | Show | Suggested narration |
|---|---|---|
| 0:00–0:15 | Welcome and anonymous session | “My question is how OceanX can keep learners engaged beyond their initial experience. This prototype compares digital-only learning with the same digital journey plus a real-world activity. The primary outcome is whether a learner actually opens the next module.” |
| 0:15–0:30 | Shared lesson and sorting | “Both groups receive the same sample ocean lesson and sorting interaction. The backend assigns a fixed group automatically. Each step is saved, and refreshing resumes the same session.” |
| 0:30–0:55 | Group B camera/preview, written observation, submit | “Group B adds Plastic Detective: learners find a plastic object and choose a reuse or reduction action. Here I capture an object, preview it and submit an observation. Photos are optional, compressed and stored privately. The save confirmation shows the submission reached the backend.” |
| 0:55–1:10 | Common quiz, meaningfulness and adult help | “Both groups answer the same comprehension questions and reflection ratings. These are supporting observations. They are not additional primary outcomes.” |
| 1:10–1:30 | Explore next journey, Ocean Habitats and saved confirmation | “The choices are equally prominent. Clicking Explore saves the choice. Continuation is recorded only after Ocean Habitats opens. The database then automatically classifies this session as Continued.” |
| 1:30–1:55 | Researcher dashboard, refresh, observation/photo and record | “The authenticated researcher dashboard retrieves the persistent session, observation and private photo. It calculates actual next-module starts divided by sessions reaching the decision, for each group. Demonstration sessions are labeled and excluded by default.” |
| 1:55–2:00 | Demo banner or About page | “This demonstrates the working intervention and measurement. These test records do not establish that the hypothesis is true.” |

## Recording checklist

1. Start the Mac preview and, if recording the iPhone camera, the private Wi-Fi preview. Keep the Mac awake.
2. Use the demonstration/test checkbox; no child names, faces, addresses or location details.
3. Show the shared lesson and virtual interaction, then the Group B activity prompt.
4. Capture or select an object-only photo, show preview/removal if useful, enter a short observation and submit.
5. Show the explicit save confirmation, common quiz and continuation choices.
6. Show Ocean Habitats loading and the saved-start confirmation.
7. Refresh the authenticated dashboard. Enable demonstration/test inclusion only for the video and keep the banner visible.
8. Show the saved observation, private photo control, exact start timestamp and automatic Continued status. Export CSV if time allows.
9. After recording, turn off demonstration/test inclusion. Do not describe demonstration percentages as participant results.
